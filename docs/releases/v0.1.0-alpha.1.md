# Cloakspan v0.1.0-alpha.1

Cloakspan is a self-hosted privacy gateway that replaces detected sensitive
values with scoped tokens before sending text to a model, then restores approved
tokens in the reply. This alpha is for local evaluation and synthetic-data pilots.

**Draft: not published.** The staging install, upgrade, rollback, and failure
rehearsal required by the roadmap has not been performed. Publication also
requires the release CI checks, image signature, and provenance described in the
[release procedure](https://github.com/quiethours-eu/cloakspan/blob/main/docs/releases/README.md).

## Try the local playground

Download `secure_ai_gateway-0.1.0a1-py3-none-any.whl` from this release's assets
into an empty directory. With Python 3.12 or newer installed, run these commands
from that directory. Installation downloads runtime dependencies; the playground
itself runs offline and needs no API key, provider account, or model download.

macOS or Linux:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install ./secure_ai_gateway-0.1.0a1-py3-none-any.whl
.venv/bin/cloakspan playground
```

Windows PowerShell:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install .\secure_ai_gateway-0.1.0a1-py3-none-any.whl
.\.venv\Scripts\cloakspan.exe playground
```

Open the loopback URL printed in the terminal, enter the session access code,
choose **Email address**, and click **Inspect locally**. The result highlights
the detected email and shows a token in its place in the projected request.
The **Credential block** example shows a request that would be refused.
Press **Ctrl+C** in the terminal to stop the playground.

The playground does not contact a model or simulate restoration. The source
archive also contains `scripts/demo.py`, which demonstrates tokenization,
restoration, blocking, and forged-token refusal with a deterministic mock provider.

## Included

- A local browser playground and the `cloakspan doctor` setup diagnostics.
- Email, IPv4, IBAN, payment-card, credential, and Baltic identifier detectors;
  country-specific coverage is documented in the README.
- YAML dictionary and regex filters for your own data formats.
- Policy decisions to allow, transform, block, or route to a local model.
- Tenant/conversation-scoped HMAC tokens and request-bound restoration.
- A documented subset of the OpenAI chat-completions API.

## Downloads and verification

- `secure_ai_gateway-0.1.0a1-py3-none-any.whl`: installable Python package.
- `secure_ai_gateway-0.1.0a1.tar.gz`: source distribution, including the offline demo.
- `requirements-runtime.lock`: versioned runtime dependencies with package hashes.
- `SHA256SUMS`: checksums for the attached packages and dependency lock.

Check a download with `sha256sum --check SHA256SUMS` on Linux, or
`shasum -a 256 --check SHA256SUMS` on macOS, with all three files in the same
directory. On Windows, compare `Get-FileHash -Algorithm SHA256 <file>` with its
entry in `SHA256SUMS`.

To use the recorded runtime dependency set, install
`requirements-runtime.lock` with `python -m pip install --require-hashes -r
requirements-runtime.lock` inside your virtual environment, then install the
wheel with `--no-deps`. A normal wheel install resolves dependencies from the
version ranges in the package metadata.

The Python distribution remains named `secure-ai-gateway`; the user-facing
command is `cloakspan`. No publication to PyPI is implied by this GitHub release.

## Current limits

This alpha is not production-ready. Contextual PERSON, ORG, LOCATION, and ADDRESS
detection needs an operator-supplied NER model. Streaming, tool calls, structured
output, multimodal input, and broad OpenAI API compatibility are unsupported.
The default vault is process-local and loses mappings on restart. Detection can
miss sensitive data; the playground is a preview, not a safety verdict.

Read the repository's
[limitations](https://github.com/quiethours-eu/cloakspan/blob/main/docs/limitations.md),
[compatibility contract](https://github.com/quiethours-eu/cloakspan/blob/main/docs/openai-compatibility.md), and
[security policy](https://github.com/quiethours-eu/cloakspan/blob/main/SECURITY.md)
before evaluating a deployment.
