# Cloakspan brand

**Cloakspan** is the public name of the project previously called Secure AI
Gateway. A cloak conceals sensitive values; a span connects an application to
its model. Use the name as one word with an initial capital.

Descriptor: **Self-hosted AI privacy gateway.**

Tagline: **Send context to the model. Keep identities local.**

The C-shaped boundary and crossing bar represent controlled passage. Keep the
mark's proportions and leave space around it. Do not imply that all sensitive
data is detected, or that every country and language is supported.

The palette extends the existing engineering diagram: deep blue `#102d40`,
diagram blue `#246b9a`, light blue `#68c7f2`, and paper `#f5f9fc`. The light blue
is for dark backgrounds; use diagram blue for text on paper. Wordmarks use
Segoe UI with a sans-serif fallback. All marks are authored vector geometry;
the PNG files are renders of their corresponding SVGs.

## Worldwide positioning

Speak to developers and organisations in any market. Lead with self-hosting,
policy control, scoped tokenization, and request-bound restoration. Use reserved
example domains and synthetic data in introductory examples.

Describe national recognizers as coverage, not the project's target geography.
The built-in national ID recognizers currently cover Latvia, Lithuania, and
Estonia. Additional country and language support requires implementation and
evaluation; worldwide positioning does not change this technical boundary.

## Compatibility

The distribution and container names remain `secure-ai-gateway`. Both
`cloakspan` and `secure-ai-gateway` launch the same application after installation.
The `gateway` import package, `SAG_*` environment variables, `sgw_live_` key
prefix, model ownership identifier, policy rule names, and deployment paths
remain stable. Historical research and evaluation results retain their original
geographic scope.

This is a repository branding change. No package registry, domain, or external
repository has been renamed or registered.
