# Support

Cloakspan is alpha software maintained on a best-effort basis.

## Where to ask

- Usage question or reproducible bug: open a GitHub issue using the appropriate
  form.
- Feature proposal: open a feature-request issue and explain the security and
  compatibility impact.
- Security vulnerability: use GitHub private vulnerability reporting as
  described in [SECURITY.md](SECURITY.md). Do not open a public issue.

Include the commit or version, operating system, Python or image version,
deployment method, sanitized configuration shape, expected result, and actual
result. Never include real prompts, API keys, vault/token keys, provider
credentials, or private endpoint addresses.

## Supported versions

Before the first tagged alpha, only the latest commit on `main` is supported.
After tagging begins, the latest alpha is supported for security fixes; older
alphas may be asked to upgrade before investigation.

There is currently no SLA, paid support, hosted service, or production-support
commitment.
